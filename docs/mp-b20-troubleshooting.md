# SII MP-B20 トラブルシューティング

## 1. iPhone と MP-B20 の Bluetooth ペアリング失敗

**症状:** iPhone の Bluetooth 設定に MP-B20 が表示されない / ペアリングできない

**確認手順:**
1. MP-B20 の電源が入っているか確認（電源ボタン長押し）
2. MP-B20 が他のデバイスに接続済みでないか確認（1対1接続）
3. iPhone の Bluetooth が ON になっているか確認
4. MP-B20 をリセット: 電源OFF → 5秒待機 → 電源ON
5. iPhone の「設定 → Bluetooth → デバイスを忘れる」で再ペアリング

**よくある原因:**
- MP-B20 のバッテリー残量不足
- 他の端末が既に接続中
- Bluetooth の距離が遠すぎる（10m以内を推奨）

---

## 2. URL Print Agent が起動しない

**症状:** 印刷ボタンを押しても何も起きない / Safari がエラーページを表示

**確認手順:**
1. App Store で「SII URL Print Agent」がインストール済みか確認
2. Safari の設定で「ポップアップブロック」が無効か確認
3. iPhone を再起動して再試行
4. Safari で `siiprintagent://` を直接入力してアプリが開くか確認

**よくある原因:**
- URL Print Agent 未インストール
- iOS のバージョンが古い
- PWA スタンドアロンモードでの URL スキーム制限（→ Safari で開き直す）

---

## 3. Agent は起動するが印刷されない

**症状:** URL Print Agent が開くが、印刷が実行されずエラーが表示される

**確認手順:**
1. URL Print Agent アプリ内でプリンターが設定されているか確認
2. アプリ内の「プリンター設定」で MP-B20 を選択
3. アプリ内のテスト印刷機能で直接印刷を試す
4. Bluetooth 接続が確立されているか確認

**エラーコード別対応:**

| Code | 意味 | 対応 |
|------|------|------|
| -10 | 通信失敗 | Bluetooth 再接続、プリンター再起動 |
| -20 | 権限エラー | iOS 設定で Bluetooth 権限を許可 |
| -30 | タイムアウト | プリンターの電源・距離を確認 |
| -40 | 無応答 | プリンターの電源OFF/ON、ペアリングやり直し |

---

## 4. 文字化け

**症状:** 印刷されるが文字が読めない / 一部の文字が欠ける

**確認手順:**
1. PDF が正しく生成されているか確認（ブラウザの開発者ツール → コンソールログ）
2. jsPDF のフォント設定を確認
3. FitToWidth パラメータが `yes` になっているか確認

**対応:**
- jsPDF のデフォルトフォント（Helvetica）は日本語非対応
- 現在の実装では FitToWidth=yes でPDF画像として印刷するため、
  PDF上で正しく描画されていれば印字も正しくなる
- 日本語が化ける場合: jsPDF に日本語フォント（NotoSansJP等）を埋め込む必要あり

---

## 5. 用紙幅の崩れ

**症状:** レシートが切れる / 余白が大きすぎる / 文字が小さすぎる

**確認手順:**
1. PaperWidth が `58` に設定されているか確認（constants.ts）
2. FitToWidth が `yes` になっているか確認
3. PDF の幅が 164pt（58mm相当）で生成されているか確認

**対応:**
- `RECEIPT_WIDTH_PT` の値を調整
- FitToWidth=yes で自動スケーリングされるが、元のPDF幅が大きすぎると文字が小さくなる

---

## 6. 改行や桁ずれ

**症状:** 金額の右寄せがずれる / 行が重なる

**確認手順:**
1. ブラウザで PDF をプレビュー生成して確認
2. receiptBuilder.ts の LINE_HEIGHT 定数を調整
3. 商品名が長い場合の折り返し処理を確認

**対応:**
- `LINE_HEIGHT` の各値を微調整
- 長い商品名は手動で折り返すロジックを追加（将来対応）

---

## 7. 一部端末だけ失敗

**症状:** 特定の iPhone でのみ印刷できない

**確認手順:**
1. iOS バージョンを確認（iOS 14 以上推奨）
2. URL Print Agent のバージョンを確認（最新に更新）
3. Safari の設定 →「Webサイトのデータ」→ キャッシュクリア
4. iPhone のストレージ空き容量を確認

---

## 8. Safari では動くが PWA では挙動が違う

**症状:** Safari で開くと印刷できるが、ホーム画面追加した PWA では動かない

**確認手順:**
1. PWA のスタンドアロンモードで URL スキームが発火するか確認
2. iOS バージョンによって PWA の URL スキーム対応が異なる

**対応:**
- iOS 16.4 以降: PWA から URL スキーム発火が可能
- それ以前: Safari で開き直す必要がある場合あり
- 回避策: PWA 内で `window.open()` を使って Safari 経由で開く

```javascript
// PWA での回避策（必要な場合）
window.open(urlScheme, '_blank')
```
